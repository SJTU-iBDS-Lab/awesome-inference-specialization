# Awesome Inference Specialization（推理系统专用化）

**从通用推理框架走向按模型、硬件和工作负载专门构建的执行系统。**

这是一个有证据标注的开源项目目录，重点收录 LLM、图像及视频领域的专用推理运行时、领域专用执行系统，以及自动生成与优化这些系统的工具。

核心关注的问题不是代码越少越好，也不是“AI 写的系统一定更快”，而是：**随着代码构建和修改成本下降，通用性是否可以更多放在构建与验证工具中，而将部署时执行程序做得更加专用？** 这是有待检验的研究假设，不是本项目已经证实的结论。

本项目**不**以 nano/教学版框架为核心，也不把一个 Kernel、一个 Python wrapper 或未经公平验证的性能数字等同于成熟的推理引擎。对于只发布部署接口、没有公开引擎源码的项目，会特别说明。
